# parser-Kwork

Telegram-бот, который следит за биржей [Kwork](https://kwork.ru/projects) и сразу
присылает новые проекты из раздела **«Скрипты, боты и mini apps»**:

| Подкатегория          | Ссылка на Kwork                               |
|-----------------------|-----------------------------------------------|
| 📜 Скрипты             | https://kwork.ru/projects?c=41&attr=7352      |
| 🕷 Парсеры             | https://kwork.ru/projects?c=41&attr=211       |
| 💬 Чат-боты            | https://kwork.ru/projects?c=41&attr=3587      |
| 📱 Telegram Mini Apps  | https://kwork.ru/projects?c=41&attr=3934090   |
| 🧠 ИИ-агенты           | https://kwork.ru/projects?c=41&attr=5548694   |
| 🤖 ИИ-боты             | https://kwork.ru/projects?c=41&attr=4158112   |

## Что умеет

- **Уведомления о новых проектах**: раз в минуту проверяет Kwork и присылает
  новые проекты: название, бюджет, число предложений, время публикации,
  описание и кнопку «Открыть на Kwork».
- **🗂 Категории**: галочками выбираете, какие подкатегории отслеживать.
- **📋 Последние заказы**: 5 самых свежих проектов по выбранным категориям.
- **🔔 Уведомления**: быстро выключить или включить рассылку.
- **Закрытый доступ**: бот может отвечать только вам.

При первом запуске бот не шлёт всю текущую ленту. Он запоминает проекты,
которые уже есть, и дальше присылает только новые.

## Вариант 1. Запуск на своём компьютере через терминал

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/)).

```bash
git clone -b claude/kwork-parser-telegram-bot-vx02ke https://github.com/gytfel/parser-Kwork.git
cd parser-Kwork
./run.sh                # Windows: run.bat (или двойной клик по нему)
```

При первом запуске откроется мастер настройки:

1. Попросит токен бота. Создайте бота у [@BotFather](https://t.me/BotFather)
   командой `/newbot` и вставьте присланный токен. Мастер сразу проверит его.
2. Спросит, разрешить ли бота только вам. Если да, напишите своему боту
   `/start` в Telegram, и мастер сам определит ваш Telegram ID.

Дальше бот запустится. Напишите ему `/start`. Остановить бота — **Ctrl+C**.

Другие команды:

```bash
./run.sh setup    # поменять токен или доступ
./run.sh check    # проверить, видит ли компьютер Telegram и Kwork
```

Бот работает, только пока открыт терминал и включён компьютер. Чтобы он
работал круглосуточно, поставьте его на VPS.

## Вариант 2. Установка на VPS (работает 24/7)

Подойдёт самый дешёвый VPS: 1 ядро, 512 МБ памяти,
**Ubuntu 22.04/24.04 или Debian 12**.

### 1. Подключитесь к серверу

После покупки VPS хостер пришлёт IP-адрес и пароль root. В терминале
(на Windows: PowerShell или «Терминал», ssh там уже есть):

```bash
ssh root@IP_СЕРВЕРА
```

При первом подключении ответьте `yes` и введите пароль (при вводе он не
отображается, это нормально).

### 2. Скачайте бота и запустите установку

```bash
apt update && apt install -y git
git clone -b claude/kwork-parser-telegram-bot-vx02ke https://github.com/gytfel/parser-Kwork.git
cd parser-Kwork
bash deploy/install.sh
```

Если вы вошли не как `root`, а как обычный пользователь, ставьте `sudo`
перед `apt` и перед `bash deploy/install.sh`.

Установщик сам:

- поставит Python и зависимости;
- скопирует бота в `/opt/kwork-bot` и создаст для него отдельного
  системного пользователя;
- запустит мастер настройки (токен и доступ, как в варианте 1);
- проверит, видит ли сервер Telegram и Kwork;
- создаст службу `kwork-bot`: бот работает в фоне, сам запускается после
  перезагрузки сервера и перезапускается при сбоях.

После этого можно закрыть терминал: бот продолжит работать.

### 3. Управление ботом на сервере

| Команда              | Что делает                                           |
|----------------------|------------------------------------------------------|
| `kwork-bot status`   | работает ли бот                                      |
| `kwork-bot logs`     | логи в реальном времени (выход — Ctrl+C)             |
| `kwork-bot restart`  | перезапустить                                        |
| `kwork-bot stop`     | остановить (`kwork-bot start` — запустить снова)     |
| `kwork-bot setup`    | поменять токен или доступ                            |
| `kwork-bot check`    | проверить связь с Telegram и Kwork                   |
| `kwork-bot config`   | открыть `.env` (прокси, интервал проверки)           |
| `kwork-bot update`   | скачать новую версию из GitHub и перезапустить        |

### Удалить бота с сервера

```bash
sudo systemctl disable --now kwork-bot
sudo rm -rf /opt/kwork-bot /etc/systemd/system/kwork-bot.service /usr/local/bin/kwork-bot
sudo systemctl daemon-reload
sudo userdel kworkbot
rm -rf ~/parser-Kwork      # папка, куда вы клонировали проект
```

Вместе с `/opt/kwork-bot` удалятся настройки (`.env` с токеном) и база.
Сам бот в Telegram при этом останется. Удалить его можно у @BotFather
командой `/deletebot`.

## Настройки (`.env`)

Мастер (`setup`) заполняет токен и доступ сам. Остальное можно поменять
руками: `kwork-bot config` на сервере, или файл `.env` в папке проекта.

| Переменная       | Что это                                                            |
|------------------|--------------------------------------------------------------------|
| `BOT_TOKEN`      | токен от @BotFather                                                |
| `ALLOWED_USERS`  | Telegram ID через запятую; пусто — бот доступен всем               |
| `CHECK_INTERVAL` | как часто проверять Kwork, в секундах (по умолчанию 60, минимум 30) |
| `DB_PATH`        | файл базы SQLite (по умолчанию `kwork_bot.db`)                     |
| `KWORK_PROXY`    | прокси для kwork.ru, например `http://user:pass@host:port`         |

## Если что-то не работает

- **Сначала запустите `check`** (`kwork-bot check` на сервере, `./run.sh check`
  на компьютере). Он покажет по отдельности, видны ли Telegram и Kwork.
- **✗ у Kwork (`HTTP 403`, `ответ не JSON`)**: Kwork часто блокирует
  зарубежные серверы. Возьмите VPS в России или укажите российский прокси
  в `KWORK_PROXY`, затем `kwork-bot restart`.
- **«Telegram не принял BOT_TOKEN»**: пройдите `setup` ещё раз и вставьте
  токен целиком.
- **Бот отвечает «Доступ закрыт»**: он покажет ваш ID. Добавьте его через
  `setup`.
- **Не запускайте один и тот же бот в двух местах сразу** (например, на
  компьютере и на сервере). Telegram отдаёт сообщения только одной копии,
  вторая будет сыпать ошибками `Conflict`.

## Как это устроено

Страница https://kwork.ru/projects подгружает ленту POST-запросом на тот же
адрес. Бот делает такой же запрос с полями `c=41` (раздел), `attr=<id>`
(подкатегория) и `page=1` и получает JSON со списком проектов. Официального
API у Kwork нет, поэтому если Kwork что-то поменяет у себя, бот может
перестать получать проекты. Это будет видно в логах как `Kwork, «…»: …`.

```
run.sh / run.bat    запуск в терминале (Linux, macOS / Windows)
deploy/install.sh   установка на VPS как службы systemd
deploy/kwork-bot    команда управления ботом на сервере
kwork_bot/
  cli.py            команды run / setup / check
  setup_wizard.py   мастер настройки .env
  app.py            запуск бота
  categories.py     подкатегории и их id на Kwork
  kwork.py          запросы к Kwork и разбор ответа
  monitor.py        фоновая проверка и рассылка новых проектов
  handlers.py       команды и кнопки бота
  keyboards.py      клавиатуры
  formatting.py     текст сообщения о проекте
  storage.py        SQLite: пользователи, подписки, уже виденные проекты
```
